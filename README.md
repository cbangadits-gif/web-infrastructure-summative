# Rwanda Electricity Tax Manager

It is web application designed for electricity companies in Rwanda to calculate, track, and manage 18% VAT(Value Added Tax) on electricity sales, ensuring compliance with RRA(Rwanda Revenue Authority) standards.


## Features

- Calculate 18% VAT on revenue (with an option for 0% exempt).
- Live Currency conversion (RWF to USD/EUR).
- Interactive history table with sorting, filtering, and searching.
- Robust error handling for invalid inputs and API downtime.

## APIs used

- **[ExchangeRate API] (https://www.exchangerate-api.com/)**: Used to fecth live exchange foreign currencies for reporting.
